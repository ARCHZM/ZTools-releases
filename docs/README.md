# ZTools manuals

Step-by-step guides for each tool. Every guide explains what the tool is for, how to use it, what each setting does and what to watch out for.

Distances in these guides are given in feet and inches unless a metric option is named.

## Stairs and railings

- [zStairByRegion](zStairByRegion.md): Stair that folds into a rectangular region (straight, L, U, Z, C)
- [zStairByCrv](zStairByCrv.md): Stair that follows a curve
- [zSpiralStair](zSpiralStair.md): Spiral stair around a center axis
- [zRailing](zRailing.md): Railing along a curve
- [zRailingSide](zRailingSide.md): Side-mounted railing and frameless glass guards

## Building envelope

- [zRoof](zRoof.md): Parametric roof with dormers
- [zWindow](zWindow.md): Parametric window in a wall
- [zWindowByCrv](zWindowByCrv.md): A row of windows along a polyline
- [zDoor](zDoor.md): Parametric door that cuts its own opening
- [zCurtainWall](zCurtainWall.md): Curtain wall system along a path
- [zLouver](zLouver.md): Louver panel on a flat face

## Site

- [zSiteContext](zSiteContext.md): Terrain, buildings, roads and more from map data
- [zSiteModifier](zSiteModifier.md): Fit a site surface to buildings or terrain

## Analysis

- [zAnalyzeTerrain](zAnalyzeTerrain.md): Elevation, slope and aspect, contour lines, analysis points
- [zAnalyzeDaylight](zAnalyzeDaylight.md): sDA, ASE and UDI daylight metrics from an EPW file
- [zAnalyzeShadow](zAnalyzeShadow.md): Shadow coverage, images and animated GIF
- [zAnalyzeView](zAnalyzeView.md): Isovist based view analysis
- [zAnalyzeViewQuality](zAnalyzeViewQuality.md): Scored view quality from a position

## Dimensions

- [zDimLength](zDimLength.md): Length and perimeter
- [zDimAngle](zDimAngle.md): Corner angles
- [zDimRadius](zDimRadius.md): Arc radius
- [zDimArea](zDimArea.md): Area
- [zDimVolume](zDimVolume.md): Volume

## Transform and utility

- [zScale](zScale.md): Batch scale
- [zArrayBetween](zArrayBetween.md): Array between two points
- [zFilletCrv](zFilletCrv.md): Batch fillet of curve corners
- [zBreakAtIntersections](zBreakAtIntersections.md): Break curves where they cross
- [zScatterToCrv](zScatterToCrv.md): Scatter copies along a curve
- [zScatterToSrf](zScatterToSrf.md): Scatter copies over a surface
- [zProjectToGround](zProjectToGround.md): Drop objects onto the ground
- [zTextureMappingByObjects](zTextureMappingByObjects.md): Per-object box texture mapping
- [zStraighten](zStraighten.md): Align the longest edge to the X axis
- [zPackObjects](zPackObjects.md): Pack footprints in a rectangle
- [zModelScaler](zModelScaler.md): Print scale and dimension converter

## Management

- [zInspector](zInspector.md): Geometry counts and quick selection
- [zLevelTag](zLevelTag.md): Tag objects by level
- [zBlockManager](zBlockManager.md): Rename, re-layer and clean up blocks
- [zSection](zSection.md): Live section clipping, real cuts and the section manager (also covers zSectionManager)
- [zRevitMapping](zRevitMapping.md): Revit category, family and type mapping
- [zImportDWG](zImportDWG.md): Tidy layers after a Revit DWG import

## View and appearance

- [zSetCamera](zSetCamera.md): Two-point perspective camera
- [zLockAspectRatio](zLockAspectRatio.md): Lock and unlock a floating viewport ratio (covers zUnlockAspectRatio)
- [zFaceCamera](zFaceCamera.md): Turn faces toward the camera
- [zThemeSettings](zThemeSettings.md): Dialog colors and light or dark mode
